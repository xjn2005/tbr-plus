# tbr++ 0.1.0：本地批注与摘录导出

## 目标与范围

`0.1.0` 让 GTK 阅读器的文字选区成为可长期保存、回到原文、导出的摘录。它只覆盖 EPUB、TXT、HTML 与 Haodoo 的 GUI 阅读流程；终端端、跨书检索、书库浏览、PDF 与 Markdown 输入不在本版本范围内。

设计原则：本地优先、低摩擦记录、锚点可恢复、导出不锁定用户数据。批注功能是阅读界面的延伸，不另建知识管理窗口。

## 架构

```
GTK 选区、浮层、侧栏
          |
          v
annotations：纯 Rust 模型、锚点、存储、导出
          |
          v
tbr-plus.sqlite
```

新增 `src/annotations/`：

- `model.rs` 定义 `BookId`、`Annotation`、颜色、标签和导出条件。
- `anchor.rs` 创建、验证和重连锚点。
- `store.rs` 管理 `tbr-plus.sqlite`、schema 版本迁移和 CRUD。
- `export.rs` 产生稳定的 Markdown。

该模块不引用 GTK。GUI 只将当前书、选区和用户操作转换为模块 API 调用。

批注数据库独立于既有 `history.sqlite`：阅读历史可被清理，而批注不会受影响。数据库存放于现有配置目录，并在首次使用时创建；schema 使用独立版本表升级。

## 身份与锚点

每本书初次打开时计算稳定 `book_id`。其输入是容器文件内容与可取得的、规范化的书内题名/作者元数据；结果使用 SHA-256。路径仅作为最近打开位置和显示信息保存，不参与身份判断，因此移动或改名不会丢失批注。

每条批注保存：

- `annotation_id`、`book_id`、`inner_book`、`chapter`、`line`、`start_char`、`end_char`；
- `quote`、`prefix`、`suffix`；
- `color`、可选 `note`、创建和更新时间；
- 通过关联表保存的零到多个标签。

坐标用于快速重绘与跳转。跳转前验证坐标处原文；若不匹配，先在原章节中用 `quote + prefix + suffix` 重新定位，再以精确原文匹配降级。不能重连时保留摘录，在侧栏标记“暂时无法回到原处”，绝不静默丢弃数据。

## GTK 交互与视觉

拖选文字后，贴近选区显示非模态浮层：四个低饱和颜色（黄、蓝、绿、红）、批注、复制和撤销。选颜色立即创建高亮、写入数据库并保留阅读焦点；“批注”才展开同一浮层内的多行说明与标签输入。标签可用空格或逗号分隔，保存不要求填写说明。

持久高亮使用主题适配的半透明底色；临时选区继续使用系统选择色，二者必须清晰区分。四种颜色在明暗主题下均保持可读性，避免高饱和或厚重描边。

侧栏 `Stack` 新增“批注”页，与目录、词典、搜索使用相同图标尺寸、间距和导航模式。卡片依次呈现章节、摘录、说明、标签与日期；点击回跳，编辑、删除、导出仅在悬停或菜单中出现。空状态只显示一条简洁提示：选择文字即可开始摘录。

右键菜单和快捷键复用相同批注动作。`Ctrl+C` 仍复制选区，词典取词逻辑保持原行为。

## Markdown 导出

用户可以导出当前书的全部批注或按标签筛选的批注到单个 Markdown 文件。默认格式按书名分组，每则摘录输出引用块、章节、说明与标签。导出对话框有一个可选的 YAML front matter 开关，默认关闭。

输出顺序固定为书名、章节、位置、创建时间，日期采用 ISO-8601 UTC 格式；相同数据重复导出得到相同内容，适合 Git 比较。第一版不做 Obsidian、Notion 或其他服务的专用同步。

## 错误处理

无法建立或写入数据库时，界面显示可行动的错误消息，不显示成功状态，也不改变阅读页为持久高亮。导出失败时保留原数据并说明目标文件不可写。锚点失效不会阻止查看、编辑或导出摘录。

## 验收与测试

纯 Rust 测试覆盖：UTF-8 与 CJK 字符范围、跨行选区、书籍身份、锚点序列化与重连、标签查询、数据库迁移、CRUD 和稳定 Markdown 输出。

GUI 验证使用可公开的小测试书，覆盖中文横排、中文竖排、多章节英文 EPUB、HTML 和 TXT：创建、显示、撤销、编辑、回跳、导出，以及移动或改名后重开书籍。日常 CI 运行 `cargo fmt --check`、`cargo clippy --all-targets --all-features -- -D warnings`、`cargo test --all-features` 和 `cargo build --no-default-features`。
